📏 Pertidaksamaan Linear Dua Variabel (PtLDV)
PtLDV adalah pertidaksamaan yang memuat dua variabel berpangkat satu, misalnya 2x + 3y ≤ 12. Daerah penyelesaiannya adalah himpunan titik (x, y) yang memenuhi pertidaksamaan, digambarkan sebagai daerah yang diarsir.
Garis
2x + 3y = 12
Tanda
≤
Uji Titik
(0, 0) ✓

📌 Kesimpulan

Karena (0,0) memenuhi 2(0) + 3(0) ≤ 12, maka daerah penyelesaian terletak di sisi yang memuat titik asal O(0,0).

Langkah Menggambar Daerah Penyelesaian
1. Gambar garis ax + by = c (garis penuh untuk ≤ / ≥, putus-putus untuk < / >).
2. Ambil satu titik uji (biasanya O(0,0)).
3. Substitusikan ke pertidaksamaan. Jika benar, arsir sisi yang memuat titik uji. Jika salah, arsir sisi sebaliknya.

📐 Sistem Pertidaksamaan Linear Dua Variabel (SPtLDV)
SPtLDV adalah kumpulan dua atau lebih PtLDV. Penyelesaiannya adalah irisan (daerah milik bersama) dari semua daerah penyelesaian masing-masing pertidaksamaan.
Pertidaksamaan 1
x + y ≤ 6
Pertidaksamaan 2
x + 2y ≤ 8
Syarat
x ≥ 0, y ≥ 0

📌 Kesimpulan

Daerah penyelesaian SPtLDV adalah irisan dari semua daerah penyelesaian pertidaksamaannya. Titik-titik sudut daerah irisan disebut titik pojok.

Cara Menentukan Himpunan Penyelesaian SPtLDV
1. Gambar daerah penyelesaian masing-masing pertidaksamaan.
2. Tentukan irisan (daerah bertumpuk) dari semua daerah.
3. Tentukan titik pojok (titik potong garis-garis pembatas yang berada di daerah irisan).
🧠 Soal – Sistem Pertidaksamaan Linear Dua Variabel
Kerjakan 3 soal berikut! Jawabanmu akan langsung tercatat untuk guru.
1. Titik yang memenuhi sistem x + y ≤ 6; 2x + y ≥ 8; x ≥ 0; y ≥ 0 adalah ....
2. Toko kue: Kue A perlu 200 g tepung & 100 g gula; Kue B perlu 100 g tepung & 150 g gula. Tersedia 4.000 g tepung & 3.000 g gula. Model matematika yang tepat adalah ....
3. Titik pojok dari sistem x + y ≤ 4; x + 3y ≤ 6; x ≥ 0; y ≥ 0 adalah ....
🎯 Tujuan: Melihat bagaimana SPtLDV dipakai untuk memodelkan masalah nyata dan menentukan solusi optimal.
🧩 Penerapan: Model Matematika & Daerah Fisibel
Ketika menghadapi soal cerita, kita ubah dulu ke bentuk SPtLDV. Daerah penyelesaiannya disebut daerah fisibel. Titik-titik pojoknya dapat diuji untuk mencari nilai optimum.

📌 Kesimpulan

Daerah fisibel dibatasi: x + y ≤ 6, 2x + y ≤ 8, x ≥ 0, y ≥ 0. Titik pojok: O(0,0), A(4,0), B(2,4), C(0,6). Nilai optimum fungsi objektif selalu terjadi di salah satu titik pojok.
